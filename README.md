# Reservasi Lapangan

Project aplikasi web untuk mengelola data lapangan dan reservasi menggunakan PHP dan MySQL.

## Fitur
- Menambah, mengedit, dan menghapus data lapangan.
- Menambah, mengedit, dan menghapus reservasi.
- Mengelola status reservasi.
- Menyelesaikan reservasi.

## Teknologi
- PHP
- MySQL
- HTML
- Composer

## Cara Menjalankan
1. Simpan folder project di `C:\laragon\www\`.
2. Jalankan Apache dan MySQL melalui Laragon.
3. Import database `reservasi_lapangan.sql` melalui phpMyAdmin.
4. Sesuaikan koneksi database di file `src/Database.php`.
5. Buka `http://localhost/Reservasi-lapangan/` di browser.
